# Настройка функциональности сообществ

## Обзор

Реализована полноценная система сообществ с возможностью:
- Создания сообществ пользователями
- Присоединения к сообществам
- Создания постов в сообществах
- Просмотра постов других участников

## Backend изменения

### Новые сущности:
- `Community` - основная сущность сообщества
- `CommunityMember` - участники сообществ
- `CommunityPost` - посты в сообществах
- `CommunityCategory` - категории сообществ

### API endpoints:
- `GET /communities` - получить все сообщества
- `GET /communities/my` - получить сообщества пользователя
- `GET /communities/:id` - получить сообщество по ID
- `POST /communities` - создать сообщество
- `PATCH /communities/:id` - обновить сообщество
- `DELETE /communities/:id` - удалить сообщество
- `POST /communities/:id/join` - присоединиться к сообществу
- `POST /communities/:id/leave` - покинуть сообщество
- `GET /communities/:id/posts` - получить посты сообщества
- `POST /communities/:id/posts` - создать пост в сообществе
- `GET /communities/categories` - получить категории

## Frontend изменения

### Новые компоненты:
- `Community.vue` - обновлен для работы с реальными данными
- `CommunityDetail.vue` - детальный просмотр сообщества с постами
- `communitiesService.js` - сервис для работы с API

### Новые маршруты:
- `/community` - список сообществ
- `/community/:id` - детальный просмотр сообщества

## Установка и настройка

### 1. Запуск миграций
```bash
cd backend
npm run migration:run
```

### 2. Инициализация категорий (опционально)
```bash
cd backend
npm run ts-node src/communities/init-communities.ts
```

### 3. Запуск приложения
```bash
# Backend
cd backend
npm run start:dev

# Frontend
cd frontend
npm run serve
```

## Использование

### Создание сообщества:
1. Перейдите на страницу "Сообщества"
2. Нажмите "Создать сообщество"
3. Заполните форму (название, описание, категория)
4. Нажмите "Создать"

### Присоединение к сообществу:
1. Найдите интересное сообщество в списке
2. Нажмите "Присоединиться"
3. Теперь вы можете создавать посты в этом сообществе

### Создание постов:
1. Откройте сообщество, к которому вы присоединились
2. В поле "Поделитесь своими мыслями..." введите текст
3. При необходимости добавьте изображение
4. Нажмите "Опубликовать"

## Структура базы данных

### Таблица `community_category`
- `id` - первичный ключ
- `name` - название категории
- `icon` - иконка категории
- `isActive` - активна ли категория
- `createdAt` - дата создания

### Таблица `community`
- `id` - первичный ключ
- `name` - название сообщества
- `description` - описание
- `image` - изображение сообщества
- `isPrivate` - приватное ли сообщество
- `categoryId` - ID категории
- `creatorId` - ID создателя
- `createdAt` - дата создания
- `updatedAt` - дата обновления

### Таблица `community_member`
- `id` - первичный ключ
- `userId` - ID пользователя
- `communityId` - ID сообщества
- `isModerator` - является ли модератором
- `joinedAt` - дата присоединения

### Таблица `community_post`
- `id` - первичный ключ
- `content` - содержимое поста
- `image` - изображение поста
- `likesCount` - количество лайков
- `commentsCount` - количество комментариев
- `authorId` - ID автора
- `communityId` - ID сообщества
- `createdAt` - дата создания
- `updatedAt` - дата обновления

## Безопасность

- Все endpoints требуют аутентификации (JWT токен)
- Только создатель может редактировать/удалять сообщество
- Только участники сообщества могут создавать посты
- Проверка прав доступа на уровне сервиса
