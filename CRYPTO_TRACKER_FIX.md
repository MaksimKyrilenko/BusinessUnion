## Если данные всё ещё не отображаются:

1. Проверьте, что backend запущен и доступен на `http://localhost:3001`
2. Проверьте CORS настройки (должны быть разрешены запросы с frontend)
3. Проверьте, что API ключи валидны и не истекли
4. Проверьте лимиты API (CoinGecko имеет лимиты на количество запросов)

## Формат данных, который ожидает frontend:

```javascript
{
  name: string,           // "Bitcoin"
  symbol: string,         // "BTC"
  icon: string,           // URL изображения
  price: number,          // 88296
  change: number,         // 1.47021
  volume24h: number,      // 77356614899
  marketCap: number       // 1763206341634
}
```

## Формат данных, который возвращает backend:

```javascript
{
  id: string,
  name: string,
  symbol: string,
  current_price: number,
  price_change_percentage_24h: number,
  total_volume: number,
  market_cap: number,
  image: string,
  last_updated: string
}
```

Маппинг происходит в функции `fetchTopCoins` во frontend.
